# 비트에서 LLM 양자화까지

컴퓨터가 숫자를 저장하는 방식부터 4비트 LLM 양자화와 실제 추론 엔진까지 연결해서 설명하는 한국어 오픈 문서 프로젝트입니다.

## 이 프로젝트가 답하려는 질문

- 컴퓨터는 정수와 실수를 비트로 어떻게 저장하는가?
- FP32, FP16, BF16은 무엇이 다른가?
- 실수 가중치를 4비트 정수 코드로 바꾸면 무엇을 잃는가?
- 역양자화한 값은 원래 값이 아닌데도 왜 모델이 작동하는가?
- 레이어를 지날수록 생기는 오차는 어떻게 관리되는가?
- GPTQ, AWQ, GGUF Q4_K_M, NF4는 무엇이 다른가?
- 양자화가 메모리는 줄이지만 역양자화 연산을 추가하는데도 왜 빨라질 수 있는가?
- 같은 4비트 모델이 llama.cpp와 vLLM에서 왜 다르게 동작하는가?

## 설명 원칙

1. 트랜스포머를 모른다고 가정한다.
2. 손으로 계산할 수 있는 작은 예제부터 시작한다.
3. 개념 → 수식 → NumPy 코드 → 실제 LLM 현상의 순서로 연결한다.
4. 양자화의 장점뿐 아니라 정확도 손실과 실패 조건도 함께 보여준다.
5. 파일 형식, 양자화 알고리즘, 실행 커널을 서로 구분한다.

## 전체 구성

| 부 | 주제 | 대표 실습 |
|---|---|---|
| 1 | 이진수와 정수 표현 | 4비트로 표현 가능한 16개 상태 확인 |
| 2 | 부동소수점 표현 | 0.1의 IEEE 754 비트열 확인 |
| 3 | 낮은 정밀도와 신경망 | FP32·FP16 행렬곱 오차 비교 |
| 4 | 정수 양자화의 기본 | scale, zero point, INT4 양자화·역양자화 |
| 5 | 신경망 4비트 양자화 | 작은 Dense 모델의 로짓 순위 비교 |
| 6 | LLM 양자화와 실행 | GPTQ·AWQ·GGUF·Marlin·VRAM 비교 |

자세한 집필 계획은 [`docs/00-project-plan.md`](docs/00-project-plan.md)에 있습니다.

## 첫 번째 실행 예제

`examples/01_dense_int4_logits.py`는 트랜스포머가 아닌 2층 Dense 분류 모델을 사용합니다.

- 원본 FP32 가중치를 대칭형 INT4로 양자화합니다.
- 역양자화한 가중치는 원본과 다르다는 것을 확인합니다.
- 원본과 양자화 모델의 로짓 차이를 측정합니다.
- 전체 테스트 샘플에서 top-1 예측 일치율을 계산합니다.
- 분류 마진이 충분한 샘플에서는 로짓 순위가 유지되는 모습을 보여줍니다.
- 결정경계 근처에서는 작은 오차로 순위가 바뀔 수 있다는 반례도 찾습니다.

### 실행

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python examples/01_dense_int4_logits.py
```

### 현재 예제 결과

```text
FP32 정확도: 100.00%
INT4 정확도: 100.00%
top-1 예측 일치율: 100.00%
전체 로짓 순위 일치율: 96.28%
```

가중치와 로짓 값은 달라졌지만, 테스트 샘플의 가장 큰 로짓 클래스는 모두 유지됐습니다. 다만 2등과 3등처럼 서로 가까운 로짓의 순서는 일부 샘플에서 바뀌었습니다.
