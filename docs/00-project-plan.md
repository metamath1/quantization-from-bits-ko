# 집필 계획

## 프로젝트의 중심 질문

이 문서는 단순히 양자화 도구 사용법을 정리하지 않는다. 다음의 인과관계를 이해하는 것이 목표다.

```text
숫자의 비트 표현
→ 표현 가능한 값과 반올림 오차
→ 낮은 정밀도의 행렬 연산
→ 가중치 양자화와 역양자화
→ 레이어 출력 오차
→ LLM 정확도·메모리·속도 변화
```

---

## 1부. 이진수와 정수 표현

### 학습 목표

- 비트와 바이트를 설명할 수 있다.
- 4비트가 16개 상태를 표현한다는 의미를 이해한다.
- unsigned 정수와 signed 정수를 구분한다.
- 2의 보수로 음수를 표현하는 원리를 이해한다.

### 핵심 예제

- 0부터 15까지 4비트 이진수로 출력하기
- signed INT4를 `-8~7`로 해석하기
- 같은 비트열이 자료형에 따라 다른 숫자가 되는 예제

---

## 2부. 부동소수점 표현

### 학습 목표

- 부호, 지수, 가수의 역할을 이해한다.
- FP32, FP16, BF16의 표현 범위와 정밀도를 비교한다.
- `0.1`이 이진 부동소수점으로 정확히 표현되지 않는 이유를 이해한다.
- overflow, underflow, rounding을 구분한다.

### 핵심 예제

- NumPy로 FP32 비트열 분해
- 서로 인접한 표현 가능 실수 사이의 간격 확인
- FP16과 BF16에서 큰 값·작은 값 표현 비교

---

## 3부. 낮은 정밀도와 신경망

### 학습 목표

- 가중치, activation, 출력, 누산 정밀도를 분리해 설명한다.
- FP16/BF16 행렬곱의 오차를 측정한다.
- 혼합 정밀도가 필요한 이유를 이해한다.

### 핵심 예제

- 같은 행렬곱을 FP64, FP32, FP16으로 실행
- 입력 스케일에 따라 오차가 달라지는 모습 확인
- 합산 순서에 따른 부동소수점 결과 차이

---

## 4부. 정수 양자화의 기본

### 학습 목표

- scale과 zero point를 사용한 affine quantization을 설명한다.
- 대칭형·비대칭형 양자화를 구분한다.
- 양자화, 역양자화, clipping error, rounding error를 구분한다.
- per-tensor, per-channel, group-wise 양자화를 비교한다.

### 핵심 예제

- 1차원 배열을 INT4로 양자화하고 복원
- group size를 128, 32, 8로 바꾸며 MSE와 저장 오버헤드 비교
- outlier 하나가 전체 scale에 미치는 영향 확인

---

## 5부. 신경망의 4비트 가중치 양자화

### 학습 목표

- W4A16의 의미를 설명한다.
- 역양자화된 가중치가 원본 가중치와 다름을 이해한다.
- 가중치 오차와 레이어 출력 오차가 서로 다름을 이해한다.
- 로짓 값이 달라져도 순위와 예측이 유지될 수 있음을 확인한다.
- 마진이 작은 샘플에서 예측이 바뀔 수 있음을 이해한다.

### 중심 실험

2차원 입력, 3개 클래스, 2층 Dense 모델을 사용한다.

```text
입력 2차원
→ Dense(2, 12)
→ tanh
→ Dense(12, 3)
→ logits
```

원본 FP32 모델과 INT4 weight-only 모델을 비교한다.

측정 항목:

- 가중치 MSE
- 로짓 MAE와 최대 오차
- top-1 예측 일치율
- 전체 로짓 순위 일치율
- 원본 모델의 분류 마진별 일치율
- 결정경계 근처의 순위 반전 사례

이 예제는 트랜스포머 없이 양자화의 핵심을 보여준다. LLM의 최종 출력도 결국 로짓 순위와 확률 분포를 사용한다는 점에서 개념적으로 연결된다.

---

## 6부. LLM 양자화와 실제 실행

### 학습 목표

- PTQ와 QAT를 구분한다.
- calibration 데이터의 역할을 이해한다.
- GPTQ, AWQ, NF4, GGUF K-quant의 핵심 차이를 설명한다.
- 파일 형식, 양자화 알고리즘, 실행 커널을 구분한다.
- 양자화가 줄이는 메모리와 줄이지 못하는 메모리를 구분한다.
- 역양자화 비용과 메모리 대역폭 절감의 관계를 설명한다.

### 실제 사례

- Qwen3.6-35B-A3B GGUF Q4_K_M + llama.cpp
- Qwen3.6-35B-A3B GPTQ Int4 Safetensors + vLLM/Marlin
- 전체 파라미터와 활성 파라미터가 다른 MoE의 메모리·연산 특성
- CPU offload가 토큰 생성 속도에 미치는 영향

## 집필 원칙

- 각 장은 앞 장의 개념만 전제로 한다.
- 수식은 반드시 작은 숫자 예제로 먼저 설명한다.
- 코드에는 출력 예시와 해석을 함께 둔다.
- 정확도를 유지한다는 표현은 원본과 완전히 동일하다는 의미로 사용하지 않는다.
- 성공 예제와 실패 예제를 함께 제시한다.
